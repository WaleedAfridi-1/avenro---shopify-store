# AVENRO — Shopify Store

**AVENRO** is a modern premium fashion e-commerce store focused on clean design, everyday comfort, and a smooth shopping experience.

> 🚧 **Project Status:** In Development — The store is currently being built and will be completed soon.

## About

AVENRO is being developed as a modern **Shopify-powered fashion storefront** for a direct-to-consumer (DTC) brand.

The goal is to create a clean, responsive, and production-ready e-commerce experience for modern everyday fashion.

## Tech Stack

* Next.js
* TypeScript
* Tailwind CSS
* Shopify Storefront API
* Node.js & Express
* MongoDB

## Planned Features

* Responsive fashion storefront
* Product collections
* Product detail pages
* Product search & filtering
* Shopping cart
* Shopify checkout
* Wishlist
* Customer accounts
* Product reviews
* Newsletter
* Responsive mobile navigation
* SEO-friendly pages
